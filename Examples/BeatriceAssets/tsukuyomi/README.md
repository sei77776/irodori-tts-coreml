# つくよみちゃん（Beatrice v2 ファインチューニング版）

このフォルダは、リアルタイム変声画面の声「つくよみちゃん」の Core ML モデルと話者データです。

## クレジット（必須表記）

本ソフトウェアの音声合成には、フリー素材キャラクター「つくよみちゃん」（© Rei Yumesaki）が無料公開している音声データを使用しています。
■つくよみちゃんコーパス（CV.夢前黎）
https://tyc.rei-yumesaki.net/material/corpus/

上の文面は、つくよみちゃんコーパス利用規約「③声質を使用した音声合成ソフト等を公開する」が示すテンプレート
（https://tyc.rei-yumesaki.net/material/corpus/ 、2026-10-06 に確認）をそのまま使っています。
規約上、この文面を目立つところに十分な文字サイズで掲載する場合は事前連絡が不要とされています。
アプリでは「つくよみちゃん」を選んでいる間、声の設定のすぐ下に表示し、クレジット欄にも常に表示します。
有料で公開する場合は、料金を支払う前に確認できる場所（ストアの説明文など）にも掲載が必要です。
つくよみちゃんのキャラクターデザイン（イラスト）は使っていないため、イラストのクレジットは載せていません。

## 出力音声の禁止事項（アプリ内にも表示）

つくよみちゃんの声を選んだ場合は、出力した音声を次の目的で使用することを禁止します。

【禁止事項】
■人を批判・攻撃すること。（「批判・攻撃」の定義は、つくよみちゃんキャラクターライセンス https://tyc.rei-yumesaki.net/about/terms/ に準じます）
■特定の政治的立場・宗教・思想への賛同または反対を呼びかけること。
■刺激の強い表現をゾーニングなしで公開すること。
■他者に対して二次利用（素材としての利用）を許可する形で公開すること。

## 中身と作り方

- `BeatriceFP32.mlpackage`: 全 FP32 の複数関数モデル（w64 / w116 / w216）。容量を抑えるため、このパックは FP16 混合（軽量）版を同梱しない。アプリで「軽量」を選んでも、この声では高音質で動く
- `voice_000.bin`, `common.bin`, `voices.json`: 話者データ（形式は親フォルダと同じ）
- 元: beatrice-trainer 2.0.0-rc.0（MIT）の事前学習モデル（LibriTTS-R 200 話者）を、つくよみちゃんコーパスで 10,000 ステップ追加学習したチェックポイント。他の話者の声質とのマージはしていない。ボコーダの重みも変わるため、モデルは事前学習版（親フォルダ）とは別物
- コーパスの音声そのもの（およびその一部）は、このリポジトリにもアプリにも含めない（コーパスの再配布は禁止）
- 書き出し: `Beatrice/tools/export_ios_assets.py`（docstring と `Beatrice/tools/packs/tsukuyomi.json` を参照）。検証用の参照データは `Tests/BeatriceVCTests/GoldenTsukuyomi/`

このモデルを改変・再配布する場合は、つくよみちゃんコーパスに由来する部分の取り扱いについて、つくよみちゃんコーパスの利用規約に従ってください。
